# Warix

Company website for [warix.co](https://warix.co).

Warix is the parent company behind software (S1 One, S2 Two) and hardware (H1, H2).

- **Software** — `/software`, apps at `one.warix.co` / `two.warix.co`
- **Hardware** — `/hardware` with purchase flow on warix.co
- **Account** — `account.warix.co` (handoff mocked in this UI)
- **Support / Company** — `/support`, `/company`

```bash
npm install
npm run dev
```

Use the **Mock states** control (bottom-left in development) to flip signed-in, bag, and checkout scenarios.
